🟢 key={product.id}
Keys are stable IDs: 1, 2, 3, 4
Before
id=1🖱️Mouse
id=2⌨️Keyboard
id=3🔌USB-C Hub
id=4💻Laptop Stand
After — Keyboard deleted
id=1🖱️Mouse✓ same
id=3🔌USB-C Hub✓ same
id=4💻Laptop Stand✓ same
React removes only Keyboard.
1 DOM operation.
Keys = Identity

key={index} — positions shift when items change.
React gets confused, re-renders the wrong things.

key={product.id} — stable, unique, never shifts.
React knows exactly what changed.

Always use a unique ID from your data.
