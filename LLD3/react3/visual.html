🔴  key = {index}

Array index shifts when items are removed

Before

key=1Keyboard

After
key=0Mouse✓ same
key=1Hub⚠ was Keyboard!
key=2Stand⚠ was Hub!
React is confused. key=1 used to be Keyboard, now it's Hub. Same key, different data — unnecessary re-renders and state bugs.

React knows exactly what happened. key=2 disappeared — only Keyboard removed. Keys 1, 3, 4 untouched. Minimal work.
