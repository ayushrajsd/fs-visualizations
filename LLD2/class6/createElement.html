Welcome! Let's learn how JavaScript adds elements to a webpage.
createElement()
Creates a DOM element object in JavaScript memory. NOT visible.
↓
appendChild()
Attaches it to the DOM tree.
↓
Browser re-renders
Element becomes visible on the webpage.

JavaScript does NOT draw elements on the screen.
JavaScript modifies the DOM.
The browser renders whatever exists inside the DOM.
